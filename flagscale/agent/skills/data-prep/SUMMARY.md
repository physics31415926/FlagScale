# Data-Prep — Summary

Prepare training data for FlagScale in Megatron binary format (.bin/.idx).

**Load when**: preparing training data, converting datasets to Megatron format, setting up tokenization, or debugging data pipeline issues.

Two pipelines: GPT-style (pretraining with document-level tokenization) and instruction-style (SFT with chat templates). Covers tokenizer selection, data conversion, blending ratios, and validation.
