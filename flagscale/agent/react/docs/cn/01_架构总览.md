# FlagScale Agent — 架构总览

## 1. 简介

FlagScale Agent 是一个 **ReAct（推理 + 行动）智能体**，专为自主模型迁移和分布式训练任务设计。它将 LLM（Claude/GPT）封装在结构化循环中，交替进行状态推理和工具调用，并叠加多层安全与效率机制。

## 2. 核心循环

```
用户任务
    │
    ▼
┌─────────────────────────────────────────────┐
│              ReactAgent.run()                │
│                                             │
│  ┌─────────┐    ┌──────────┐    ┌────────┐ │
│  │ Prompt  │───▶│ LLM 调用 │───▶│ 解析   │ │
│  │ 构建    │    │(流式输出) │    │ 响应   │ │
│  └─────────┘    └──────────┘    └────────┘ │
│       ▲                              │      │
│       │         ┌──────────┐         │      │
│       │         │  Gate    │◀────────┘      │
│       │         │(执行前)  │                │
│       │         └────┬─────┘                │
│       │              │                      │
│       │         ┌────▼─────┐                │
│       │         │工具执行  │                │
│       │         │(可并行)  │                │
│       │         └────┬─────┘                │
│       │              │                      │
│       └──────────────┘                      │
│         (结果追加到历史)                     │
└─────────────────────────────────────────────┘
```

## 3. Mixin 组合

`ReactAgent` 通过多重继承组合：

| Mixin | 职责 |
|-------|------|
| `PromptMixin` | 系统提示词构建、情境上下文 |
| `CompactionMixin` | 上下文窗口管理、消息压缩 |
| `GatesMixin` | 执行前安全门控（硬阻断 + 软警告） |
| `JudgesMixin` | LLM-as-Judge 评估（技能匹配、质量） |
| `CommandsMixin` | 用户斜杠命令（/plan, /memory, /status） |
| `LoopDetectMixin` | 重复工具调用检测与缓存 |
| `CheckpointMixin` | 错误时主动记忆召回 |
| `PollMixin` | 长时间操作的非 LLM 轮询 |
| `SkillLifecycleMixin` | 技能加载、阶段转换、错误升级 |

## 4. 核心子系统

### 4.1 历史与压缩
- `HistoryManager`：Token 计数、消息存储、压缩触发
- `CompactionMixin`：多比例压缩 + 评分器 + 丢弃前记忆转储

### 4.2 Gate 系统
- 31 个 Gate 方法（硬阻断 + 软警告）
- 执行前：阻止危险/过早的操作
- 执行后：验证结果后再继续

### 4.3 技能生命周期
- 6 阶段严格有序：分析 → 结构实现 → 结构验证 → 数据管道 → Checkpoint 转换 → 训练验证
- 错误模式追踪 + 修复指纹
- 基于 LLM 的语义去重（防止重复尝试相同修复）

### 4.4 记忆与实验
- `SessionMemory`：带 TTL、优先级、相关性查询的键值存储
- `ExperimentManager`：结构化实验/尝试追踪 + 经验教训

### 4.5 计划管理
- `TaskPlan`：步骤式计划 + 自动同步 + 一致性检查 + 重建建议

### 4.6 工具系统
- 18 个注册工具，支持 OpenAI/Anthropic Schema 生成
- 通过 ThreadPoolExecutor 并行执行
- 文件缓存（TTL + mtime）用于读取去重

## 5. 数据流

```
用户消息
    → HistoryManager（Token 预算检查）
    → PromptMixin（构建系统提示词 + 情境上下文）
    → LLM Provider（流式响应）
    → 解析工具调用
    → LoopDetectMixin（去重检查）
    → GatesMixin（执行前门控）
    → 工具执行（独立调用可并行）
    → GatesMixin（执行后验证）
    → SkillLifecycleMixin（阶段追踪、错误升级）
    → 结果追加到历史
    → CompactionMixin（超预算则压缩）
    → 下一轮迭代或返回用户
```

## 6. 配置

`AgentConfig`（dataclass）从 YAML 加载：
- `provider`：LLM 后端（anthropic/openai）
- `model`：模型标识
- `max_context_tokens`：上下文窗口预算
- `max_output_tokens`：单次响应 Token 上限
- `temperature`：采样温度
- `tools_enabled`：启用的工具列表
- `skills_dir`：技能定义路径

```
├── compact.py            # CompactionMixin — 评分器、记忆转储
├── prompt.py             # PromptMixin — 系统提示词、情境段落

├── plan.py               # TaskPlan — 步骤管理
├── skill_lifecycle.py    # SkillLifecycleMixin — 阶段、错误升级
├── loop_detect.py        # LoopDetectMixin — 去重、缓存
├── checkpoint.py         # CheckpointMixin — 主动记忆召回
├── experiment_manager.py # ExperimentManager — 尝试追踪
├── judges.py             # JudgesMixin — LLM 评估
├── commands.py           # CommandsMixin — 斜杠命令
├── poll.py               # PollMixin — 非 LLM 轮询
├── config.py             # AgentConfig 数据类
├── providers/            # LLM Provider 适配器
├── tools/                # 工具实现
├── skills/               # 技能定义（SKILL.md 文件）
├── tests/                # 测试套件（610 个测试）
└── docs/                 # 本文档
```
