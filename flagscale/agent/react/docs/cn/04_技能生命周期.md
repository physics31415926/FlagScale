# 技能生命周期

## 概述

技能生命周期系统管理 Agent 如何推进复杂的多阶段任务（尤其是模型迁移）。它强制执行严格的阶段顺序、追踪错误模式、并防止重复尝试已失败的方案。

## 6 阶段严格有序

```
analysis（分析） → structure_implementation（结构实现）
    → structure_verification（结构验证） → data_pipeline（数据管道）
    → checkpoint_conversion（Checkpoint 转换） → training_verification（训练验证）
```

每个阶段包含：
- **进入条件**：进入前必须满足的前提
- **允许操作**：该阶段可执行的工具/动作
- **退出条件**：推进到下一阶段需达成的目标

`_check_phase_ordering_gate` 硬阻断在错误阶段尝试的操作（如结构验证前做 Checkpoint 转换）。

## 错误模式追踪

### 结构化历史
`_error_pattern_history` 存储 `(pattern, fix_fingerprint)` 元组：
- `pattern`：错误签名（如 "layer3.weight shape mismatch"）
- `fix_fingerprint`：尝试修复的描述（从最近工具调用中提取）

### 修复指纹提取
`_extract_fix_fingerprint()` 检查最近的工具调用，构建修复描述：
- 文件编辑：捕获文件路径和修改性质
- Shell 命令：捕获执行的命令
- 配置修改：捕获修改的参数

### 语义去重
`_llm_judge_is_same_fix()` 使用 LLM 判断提议的修复是否与之前失败的修复本质相同。这能捕获语法略有不同但方法相同的情况。

## 错误升级

`_record_and_escalate_failure()`：
1. 记录错误模式 + 修复指纹
2. 从所有先前尝试构建 `failed_attempts_summary`
3. 将摘要注入升级消息
4. 重置 `_source_reads_since_last_failure` 计数器
5. 强调"阅读框架源码"为第一步

### 升级级别
- **第 1 次失败**：允许正常重试
- **第 2 次失败**：软警告——必须阅读框架源码
- **第 3 次及以上**：硬升级——强制诊断顺序（环境 → 依赖 → 源码 → 修复）

## 阶段转换指导

`_get_current_phase_guidance()` 提供：
- 当前阶段禁止的操作
- 推进前必须完成的事项
- 建议的下一步动作

## 集成点

- `agent.py`：将失败尝试注入轮上下文（`_build_turn_context`）
- `compact.py`：压缩时将 attempted_fixes 同步到 ExperimentManager
- `gates.py`：阶段顺序 Gate、源码阅读 Gate、错误升级 Gate
- `prompt.py`：决策段落包含分层恢复顺序
