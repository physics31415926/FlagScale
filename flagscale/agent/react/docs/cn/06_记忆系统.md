# 记忆系统

## 概述

两个互补的记忆系统提供跨会话和会话内的持久化：

1. **SessionMemory**：带 TTL、优先级和相关性搜索的键值存储
2. **ExperimentManager**：结构化实验/尝试追踪

## SessionMemory

### 存储
- 磁盘上的 YAML 文件，每个键一个文件
- 字段：`key`、`value`、`type`（finding/decision/todo/context）、`priority`、`created`、`accessed`、`access_count`

### 优先级与 TTL

| 优先级 | TTL | 用途 |
|--------|-----|------|
| `high` | 永不过期 | 关键发现、永久决策 |
| `critical` | 7 天 | 压缩检查点（自动清理） |
| `normal` | 30 天 | 标准发现和上下文 |
| `low` | 7 天 | 临时上下文 |

### 自动提升
- 访问次数 ≥3 时自动从 `normal` 提升为 `high`
- 防止重要但初始优先级低的条目过期

### 相关性查询
`query_relevant(keywords, max_tokens)`：
- 按关键词匹配 key + content 计算相关性分数
- 在 Token 预算内返回最佳匹配
- 用于错误时的主动记忆召回

### 去重
- 置信度阈值：0.7
- 写入前检查是否存在语义相似的条目
- 防止重复相似发现导致记忆膨胀

## ExperimentManager

### 数据模型
```yaml
Experiment（实验）:
  name: 名称
  purpose: 目的
  hypothesis: 假设
  status: running | completed | failed
  created: 创建时间
  attempts: List[Attempt]（尝试列表）
  root_cause: 根因
  learnings: List[str]（经验教训）

Attempt（尝试）:
  timestamp: 时间戳
  change: 本次修改内容
  hardware: {gpus, gpu_type, driver, cuda}
  config: {model, tp, dp, pp, global_batch_size, ...}
  output_dir: 输出目录
  result: 结果
```

### 集成
- `compact.py`：压缩时将 `attempted_fixes` 同步到 `learnings`
- `agent.py`：将最近失败尝试（最近 5 条）注入轮上下文
- `checkpoint.py`：错误时主动召回查询实验经验

## 主动记忆召回（CheckpointMixin）

`_proactive_memory_recall(error_text)`：
1. 从错误文本提取关键词（错误类型、模块名、配置参数）
2. 查询 SessionMemory 中的相关条目
3. 将匹配的记忆注入工具结果上下文
4. 训练失败和 Shell 错误时自动触发

### 关键词提取
`_extract_recall_keywords(text)`：
- 错误模式：OOM、NCCL、CUDA、shape mismatch
- 模块名：Layer、Module、Attention、MLP
- 配置关键词：tp、pp、dp、seq_length、batch_size

## 记忆工具

| 工具 | 用途 |
|------|------|
| `memory_write` | 存储键值对（可选优先级/类型） |
| `memory_read` | 读取指定键 |
| `memory_list` | 列出所有键及元数据 |
