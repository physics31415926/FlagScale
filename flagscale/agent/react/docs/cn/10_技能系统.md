# 技能系统

## 概述

技能是领域特定的知识包，引导 Agent 完成复杂任务。每个技能是一个 `SKILL.md` 文件，包含结构化指令、阶段指导和领域规则。

## 技能发现

`SkillManager` 扫描 `skills/` 目录下包含 `SKILL.md` 的子目录：

```
flagscale/agent/react/skills/
├── model-porter/SKILL.md     # 模型迁移方法论
├── data-prep/SKILL.md        # 数据管道准备
├── train-config/SKILL.md     # 训练配置生成
├── train-run/SKILL.md        # 训练执行
├── train-monitor/SKILL.md    # 训练监控
├── env-setup/SKILL.md        # 环境搭建
├── topo-detect/SKILL.md      # 硬件拓扑检测
├── reproduce/SKILL.md        # 基线复现
└── precision-alignment/SKILL.md  # Loss 曲线对齐
```

## 技能加载

1. **自动检测**：`JudgesMixin._skill_judge()` 通过关键词匹配将用户意图映射到可用技能
2. **手动加载**：用户可通过 `load_skill` 工具显式加载
3. **注入**：技能内容包裹在 XML 标签中注入系统提示词

## 关键技能特性

### model-porter（模型迁移）
- **Analysis 0**：强制性模型结构枚举步骤，写任何代码前必须完成
- 组件 checklist 追踪
- 模块边界处的诊断打印策略

### data-prep（数据准备）
- **关键前置条件**：并行策略文档化（TP/PP/DP/EP/CP/SP）
- 覆盖 MoE 路由、上下文并行、packed samples
- 写数据代码前必须文档化全部 6 个并行维度

## 技能集成点

| 组件 | 集成方式 |
|------|----------|
| `prompt.py` | 将技能内容注入系统提示词 |
| `gates.py` | 阶段顺序检查引用活跃技能 |
| `skill_lifecycle.py` | 管理技能内的阶段转换 |
| `agent.py` | 根据用户意图自动加载技能 |
