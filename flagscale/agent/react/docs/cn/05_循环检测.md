# 循环检测与工具调用缓存

## 概述

防止 Agent 在循环中重复执行相同的工具调用，并缓存读取结果以避免冗余磁盘 I/O。

## 循环检测

### 机制
- 维护最近工具调用键的滑动窗口（`_recent_tool_calls`，大小=10）
- 每次工具调用通过 `_get_tool_call_key()` 转换为规范键
- 同一键在窗口中出现 ≥3 次时，第 4 次尝试触发 `LOOP DETECTION` 警告

### 键生成规则

| 工具 | 键格式 |
|------|--------|
| `shell` | `("shell", 命令字符串)` |
| `read_file` | `("read_file", 路径, str(起始行), str(结束行))` |
| `write_file` | `("write_file", 路径, 内容)` |
| `edit_file` | `("edit_file", 文件路径, old_string, new_string)` |
| `load_skill` | `("load_skill", 名称)` |
| `memory_write` | `("memory_write", 键名)` |
| 其他 | `(工具名, "key1=val1;key2=val2;...")` |

### 窗口驱逐
- 窗口大小 10 条（FIFO）
- 新条目进入时旧条目被驱逐
- 因此间隔 10 次不同调用后重复的工具调用不会触发检测

## 工具调用缓存

### 可缓存工具
- `read_file`：按 `(路径, 起始行, 结束行)` 缓存
- `memory_write`：按 `(键名)` 缓存

### 缓存行为
- `_check_duplicate_read()`：键存在于 `_tool_call_cache` 时返回缓存结果
- `_cache_tool_result()`：成功执行后存储结果
- **错误不缓存**：包含 "ERROR" 的结果永不缓存
- **空路径/键不缓存**：防止垃圾条目

### 缓存失效
- `write_file` 执行后：失效对应路径的缓存
- `edit_file` 执行后：失效对应路径的缓存
- 无基于 TTL 的过期（会话级作用域）

## 文件级缓存（ReadFileTool）

独立于工具调用缓存，`ReadFileTool` 有自己的 `FileCache`：
- **TTL**：30 秒
- **mtime 验证**：文件修改时间变化则缓存失效
- **LRU 驱逐**：最多 50 条
- **显式失效**：`WriteFileTool` 和 `EditFileTool` 修改后主动调用

## 常量

```python
_LOOP_DETECTION_WINDOW = 10
_LOOP_DETECTION_THRESHOLD = 3
```
