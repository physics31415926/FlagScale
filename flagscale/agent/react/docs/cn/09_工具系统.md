# 工具系统

## 概述

工具系统为 Agent 提供具体动作能力：文件 I/O、Shell 执行、监控、验证和记忆操作。工具注册在 `ToolRegistry` 中，通过 OpenAI/Anthropic 函数调用 Schema 暴露给 LLM。

## 工具注册表

所有工具继承 `Tool` 基类并实现：
- `name`：工具标识符
- `description`：面向 LLM 的描述
- `parameters`：参数的 JSON Schema
- `execute(**kwargs) -> str`：执行逻辑

## 并行执行

通过 `ThreadPoolExecutor` 并行执行工具：
- 单次 LLM 响应返回多个工具调用时
- 调用之间无依赖关系（由 LLM 决定）

## FileCache（read_file）

- **TTL**：30 秒
- **mtime 验证**：文件被外部修改时失效
- **LRU 驱逐**：最多 50 条
- **写穿失效**：`write_file` 和 `edit_file` 修改后显式失效

## Monitor 工具

特殊的长时间运行工具，轮询时不调用 LLM：
- 监控文件或命令输出
- 返回条件：错误模式、成功模式、目标步数、进程死亡、超时
- 进程死亡检测：通过 `pgrep` 检查训练进程
- 自动扫描 FlagScale 输出目录中的 stderr.log 文件
- 结果格式化：`TRAINING CRASHED`、`TRAINING DEAD` 等清晰标题

## Inspect Checkpoint 工具

Checkpoint 深度验证：
- 加载 .pt/.bin/.safetensors 文件
- 报告：键数量、形状、数据类型、参数量
- 异常检测：NaN、Inf、全零张量
- 采样统计：均值、标准差、最小/最大值
- 期望键匹配（正则模式）
- 参考对比：与已知正确 checkpoint 的 shape/dtype 差异

## Validate Config 工具

FlagScale YAML 配置验证：
- 自动检测配置类型（顶层 vs 模型层）
- 检查必需键和有效结构
- 检测常见错误放置（bf16 在 model 下、tp 在 model 下等）
- 返回：OK、WARNINGS 或 ERRORS 并附具体指导
